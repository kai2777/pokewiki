# PokéWiki — 寶可夢互動圖鑑

探索關都地區的 151 隻寶可夢。用繁體中文、英文或全國圖鑑編號搜尋，再依 18 種屬性篩選。點開卡片即可查看身高、體重、特性、六項能力值與分支進化。

## 使用方式

- **線上使用**　直接開啟 [PokéWiki 公開網頁](https://kai2777.github.io/pokewiki/)。
- **下載使用**　[下載專案 ZIP](https://github.com/kai2777/pokewiki/archive/refs/heads/main.zip)，解壓縮整個資料夾後，雙擊其中的 `index.html`。請將 `css`、`js` 資料夾保留在原位置。

兩種方式都需要網路連線，以取得寶可夢資料與圖片。

## 資料與圖片

資料來自 [PokéAPI](https://pokeapi.co/)，圖片由 [PokéAPI sprites](https://github.com/PokeAPI/sprites) 提供。PokéWiki 是非官方、非商業教育作品。寶可夢名稱、角色與圖像權利屬其各自權利人。
